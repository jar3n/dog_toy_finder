# ROSA agent

- `agent/` - agent setup and entry points
- `tools/` - tools exposed to ROSA: `drive`, `arm`, `perception`, `navigation`, `utility`
- `prompts/` - system prompts
- `mcp_servers/` - MCP servers (e.g. toy identification, memory)
- `memory/` - persistent memory storage (db files ignored)
- `config/`, `tests/`, `examples/`
