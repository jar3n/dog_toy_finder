# Gazebo simulation

- `worlds/` - environments (e.g. living room)
- `models/` - `dogbot`, `dog_toys`, `environment`
- `launch/`, `config/` - sim launch files, bridge and controller config
- `plugins/` - custom Gazebo plugins, if needed
- `scenarios/` - repeatable test setups (toy placements, start poses)
- `tests/`

The Gazebo container lives in `../docker/gazebo/`.
